# 微信账单原图改字生成器

基于真实账单截图（1179×2556）的**纯前端**图片改字工具：在 Canvas 上按像素坐标重绘文字，实时预览并导出高清 PNG。

## 特性

- **原图底图**：以真实账单截图为背景，仅在原文字位置擦除重绘，其余像素与原件完全一致
- **可编辑项 14 项**：状态栏时间、电池电量、商户名称、交易金额、当前状态、支付时间、商品、商户全称、收单机构、支付方式、交易单号、商户单号、条形码数字、账单头像
- **状态栏还原**：固定 5G 标识；电池为无数字胶囊，白色填充宽度 = 电量百分比
- **自动填时**：打开页面自动读取系统时间填入状态栏时间与支付时间，可自行修改
- **随机生成**：交易单号（28 位）、条形码数字（25 位）一键随机，条形码图形同步重绘
- **头像替换**：上传图片圆形裁剪替换徽标，可一键恢复原图头像
- **单文件离线**：底图与数字字体（Noto Sans 子集）均以 data URI 内嵌，无需联网、无需服务器
- **免责条款**：进入页面先弹出，同意后方可使用

## 使用

直接用浏览器打开 `index.html` 即可（也可部署到 GitHub Pages / EdgeOne Pages 等静态托管）。

点击「保存高清截图到手机/电脑」导出 1179×2556 原分辨率 PNG。
